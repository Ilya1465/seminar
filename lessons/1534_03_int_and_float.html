{% section "Целочисленная арифметика" %}

Для целых чисел работают все шесть арифметических операций, но деление ведёт себя по-разному в зависимости от знака: / возвращает вещественное число типа float, а // — целое число int с отброшенной дробной частью.

{% program %} print(17 / 3) # 5.666666666666667 — деление с дробью print(17 // 3) # 5 — деление нацело print(17 % 3) # 2 — остаток от деления {% endprogram %}

Операция // соответствует div в Паскале и Кумире, а % — mod. Вместе они дают полное представление о делении: a = a // b * b + a % b.

{% table 'Три операции деления' %} ОперацияТип результатаДля 17 / 3Смысл /float5.666…деление с дробью //int5сколько раз b помещается в a %int2что осталось {% endtable %} {% warning %} // округляет вниз, а не «отбрасывает дробную часть» в обе стороны. Для отрицательных чисел это даёт разный результат: -17 // 3 равно -6, а не -5. Если нужна именно целая часть по модулю, сначала возьмите abs(). {% endwarning %} {% tip %} Остаток от деления — основа школьных проверок. Чётность: n % 2 == 0. Последняя цифра числа: n % 10. Полный круг по кругу: остаток от деления числа градусов на 360. {% endtip %} {% endsection %} {% section "Действительные числа" %}

Действительные числа имеют тип float. Чтобы считать их с клавиатуры, результат input() нужно преобразовать функцией float():

{% program %} x = float(input()) print(x) {% inputdata %} 1.492 {% endinputdata %} {% endprogram %}

Действительные числа записываются с точкой, а не с запятой: 1.492, а не 1,492. Запятая в Питоне — это разделитель аргументов, и float('1,492') завершится ошибкой.

Для очень больших и очень маленьких чисел используют запись «с плавающей точкой», её ещё называют научной. Число записывается как мантисса, буква e и порядок — без пробелов, знак минус перед порядком разрешён:

{% snippet 'Научная запись' %} 1.496e11 # расстояние от Земли до Солнца, метров 2.99e-23 # масса молекулы воды, килограммов -1.5e3 # со знаком минус {% endsnippet %} {% note %} Результат / — всегда float, а // — всегда int, независимо от типов операндов. Это отличается от многих языков, где 3 / 2 даёт целое 1 только для целочисленных типов. {% endnote %}

Преобразование float в int округляет в сторону нуля: int(1.7) даёт 1, а int(-1.7) — -1. Это отличается от floor, который округляет вниз.

{% endsection %} {% section "Округление" %}

Округлять числа приходится постоянно: от цен до средних баллов. В Питоне есть несколько способов, и они дают разные ответы на границах.

{% table 'Способы округления' %} ВызовЧто делает2.5-2.5 int(x)отбрасывает дробную часть2-2 round(x)до ближайшего целого2-2 math.floor(x)вниз, к «полу»2-3 math.ceil(x)вверх, к «потолку»3-2 {% endtable %} {% program %} import math x = 4.2 print(int(x), math.floor(x), math.ceil(x)) print(round(7.5), round(-7.5)) print(round(3.14159, 2)) {% endprogram %} {% warning %} Функция round(x) округляет половины к ближайшему чётному числу, а не вверх. Поэтому round(0.5) == 0 и round(1.5) == 2 — результаты несимметричны. Это сделано намеренно, чтобы округление работало без накопления ошибки при повторном применении. Если нужно обычное «половина вверх», пишите math.floor(x + 0.5). {% endwarning %} {% tip %} Округлять нужно в самом конце вычислений, а не после каждой операции. Округление на каждом шаге накапливает погрешность: результат может отличаться от точного на десятые доли. {% endtip %} {% endsection %} {% section "Библиотека math" %}

Для вычислений с вещественными числами в Питоне есть библиотека math. Подключается она одной строкой в самом начале программы:

{% snippet 'Подключение библиотеки' %} import math {% endsnippet %}

Дальше функции вызываются с указанием модуля. Вместо числа x можно передать переменную или любое выражение:

{% program %} import math x = math.ceil(4.2) y = math.ceil(4.8) print(x) print(y) {% endprogram %}

Если библиотека нужна один раз, можно импортировать конкретную функцию и не повторять имя модуля:

{% program %} from math import ceil x = 7 / 2 y = ceil(x) print(y) {% endprogram %}

Форма from math import * вообще не требует префикса, но её лучше не использовать в учебных программах: непонятно, откуда взялась та или иная функция, и легко случайно затенить свою переменную.
