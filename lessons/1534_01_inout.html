{% section 'Зачем это нужно' %}

В первом же занятии мы напишем программу, которая спрашивает у человека два числа, складывает их и показывает ответ. Ровно та же программа сегодня считает стоимость покупки в интернет-магазине, раскладывает зарплату по статьям бюджета или переводит температуру из градусов Цельсия в Фаренгейта. Разница только в том, откуда берутся числа: с клавиатуры, из файла или из ответа веб-сервиса.

{% keyline %} Программа — это три шага: считать данные, обработать их, вывести результат. Всё остальное в этом учебнике — детали этих трёх шагов. {% endkeyline %} {% endsection %} {% section 'Как программа получает данные на этом сайте' %}

В наших задачах вы не печатаете числа на клавиатуре — это делает сайт. Когда вы нажимаете Выполнить или Проверить, сайт запускает вашу программу и сам подаёт ей входные данные: каждая строка входа попадает в очередной вызов input() по порядку. Программа читает вход сверху вниз, как рецепт — строку за строкой.

А print() — единственный способ программы «ответить»: сайт читает весь её вывод и сравнивает с ожидаемым ответом. Посмотрите на программу ниже и нажмите Запустить: сайт сам подставит входные данные — 2 и 3: {% program %} a = int(input()) # сайт подставит первую строку входа: 2 b = int(input()) # затем вторую: 3 print(a + b) # ответ 5 сайт сравнит с ожидаемым {% endprogram %} {% inputdata %} 2 3 {% endinputdata %}

{% checklist 'Три правила ввода и вывода на сайте' %} Каждый вызов input() читает ровно одну строку входных данных print() выводит ответ — сайт сравнивает его с ожидаемым дословно Лишний текст или пробел в выводе — уже другой ответ, тест не пройдёт {% endchecklist %} {% endsection %} {% section 'Первая программа' %}

Python — это современный язык, на котором программы пишутся и читаются легко. Начнём с функции print(): она выводит на экран всё, что перечислили в круглых скобках через запятую.

Вот программа, которая делает несколько вычислений. Нажмите Запустить — код выполнится прямо в браузере, справа покажут значения переменных и результат вывода: {% program %} print(5 + 10) print(3 * 7, (17 - 2) * 8) print(2 ** 16) # две звёздочки означают возведение в степень print(37 / 3) # один слэш — деление с ответом-дробью print(37 // 3) # два слэша считают частное от деления нацело print(37 % 3) # процент считает остаток от деления нацело {% endprogram %}

{% table 'Шесть арифметических операций Python' %} ОперацияСмыслПримерРезультат +сложение5 + 1015 -вычитание17 - 215 *умножение3 * 721 /деление, всегда с дробью37 / 312.333… //деление нацело, div в других языках37 // 312 %остаток от деления, mod в других языках37 % 31 **возведение в степень2 ** 1665536 {% endtable %} {% tip %} Остаток от деления полезен не только в математике. По нему проверяют чётность числа (n % 2 == 0), определяют, какой сегодня день недели по номеру дня, и выбирают, сколько полных кругов помещается в заданное количество метров ткани. {% endtip %}

Деление / и деление нацело // путают чаще всего. Разница видна сразу: 37 / 3 даёт 12.333…, а 37 // 3 отбрасывает дробную часть и возвращает 12.

{% warning %} Считать расстояние, вес или деньги нужно через /, а не //. Округление вниз накапливается: в десяти шагах разница уже не видна, а в чеке она становится ошибкой. {% endwarning %} {% endsection %} {% section 'Как считать данные, которые вводит человек' %}

Функция input() считывает строку, введённую с клавиатуры. Программа не может предположить, что человек введёт, поэтому результат нужно сохранить в переменную — именованное место в памяти.

Переменная создаётся оператором присваивания =. Слева пишут имя, справа — любое выражение; после этого имя указывает на вычисленное значение. {% program %} print('Как вас зовут?') name = input() # считываем строку и кладём её в переменную name print('Здравствуйте, ' + name + '!') {% inputdata %} Пётр {% endinputdata %} {% endprogram %}

{% note %} Имя переменной — это любая последовательность латинских букв, цифр и подчёркиваний, которая не начинается с цифры. Имена чувствительны к регистру: name и Name — две разные переменные. Хорошее имя объясняет, что лежит внутри: price, count, answer. {% endnote %}

Теперь напишем программу, которая считывает два числа и выводит их сумму: {% program %} a = input() b = input() s = a + b print(s) {% inputdata %} 5 7 {% endinputdata %} {% endprogram %}

Программа выводит 57, хотя 5 + 7 — это 12. В третьей строке Питон сложил две строки, а не два числа: к первой строке просто приписалась вторая.

{% endsection %} {% section 'Строки и числа — разные типы' %}

В Питоне все данные называются объектами, и каждый объект относится к какому-то типу. Тип определяет, какие действия с объектом допустимы.

{% table 'Основные типы, которые встретятся в этом курсе' %} ТипЧто хранитПример значения intцелые числа42 floatдробные числа3.14 strстроки'Питон' boolистина или ложьTrue, False listсписок значений[1, 2, 3] {% endtable %}

Посмотрите на визуализатор: содержимое a и b заключено в кавычки. Это означает, что в них лежат строки, а не числа. Убедимся, что тип действительно имеет значение: {% program %} first = 5 second = 7 print(first * second) # числа умножаются first = '5' second = '7' print(first * second) # строки повторяются {% endprogram %}

Второй вывод — 575757. Умножение строки на целое число не вызывает ошибки, оно повторяет строку нужное число раз. Это не ошибка, а особенность языка, о которой полезно знать.

{% warning %} Сложить строку с числом тоже нельзя — будет ошибка TypeError. Ошибки типов встречаются чаще всего именно на вводе: человек нажал Enter, и программа получила строку вместо числа. {% endwarning %} {% endsection %} {% section 'Превращаем строку в число' %}

Функция int() преобразует строку из цифр в целое число, а float() — в дробное. После этого арифметика работает как ожидается: {% program %} a = int(input()) b = int(input()) s = a + b print(s) {% inputdata %} 5 7 {% endinputdata %} {% endprogram %}

{% tip %} Писать int(input()) нужно почти в каждой задаче, где есть ввод. Это настолько привычный приём, что в учебниках его часто опускают: считается, что новичок уже знает, что ввод возвращает строку. {% endtip %}

Если в строке есть что-то кроме цифр и знака, int() завершится с ошибкой. Разбором таких строк мы займёмся в уроке про строки.
