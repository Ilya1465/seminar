{% section "Строки" %}

Строка считывается со стандартного ввода функцией input(). Для строк определены операция сложения (конкатенация) и умножение строки на число. Длина строки — функция len.

Любой объект можно привести к строке функцией str(), а строку — к числу функциями int() и float().

{% note %} С точки зрения Питона строка — это объект класса str. Имя функции приведения типа совпадает с именем класса: str создаёт объект класса str, int — объект класса int. {% endnote %} {% program %} s = input() print(len(s)) t = input() number = int(t) u = str(number) print(s * 3) print(s + ' ' + u) {% inputdata %} What is the answer? 42 {% endinputdata %} {% endprogram %} {% tip %} print() сам приводит аргументы к строке, поэтому print(number) и print(str(number)) дают одинаковый результат. Явный str() нужен только для конкатенации: str(a) + str(b). {% endtip %} {% endsection %} {% section "Символы и индексы" %}

Строка — это последовательность символов, а позиция символа называется его индексом. Нумерация начинается с нуля:

{% table 'Индексы строки Hello' %} Индекс01234 СимволHello Индекс с конца-5-4-3-2-1 {% endtable %}

Отрицательный индекс отсчитывается с конца строки, начиная с -1. Так S[-1] — последний символ, а S[-2] — предпоследний.

{% warning %} Отдельного типа для символа в Питоне нет: результат S[i] — тоже строка типа str. Поэтому S[0] нельзя сравнивать с символом как с числом и к нему применимы строковые методы. {% endwarning %}

Если индекс больше либо равен len(S) или меньше, чем -len(S), произойдёт ошибка IndexError: string index out of range.

{% endsection %} {% section "Срезы" %}

Срез извлекает из строки фрагмент. Самая простая форма — S[i]: один символ с индексом i. Две параметра дают подстроку: S[a:b] возвращает символы с индексами от a до b - 1, то есть правый границу в результат не включается.

{% table 'Формы срезов' %} СрезЧто вернёт для 'abcdefg' s[1]'b' — один символ s[-1]'g' — с конца s[1:3]'bc' — со второго по третий s[1:-1]'bcdef' — без первого и последнего s[:3]'abc' — от начала s[3:]'defg' — до конца s[:-1]'abcdef' — без последнего s[:]'abcdefg' — вся строка, копия s[::2]'aceg' — каждый второй s[::-1]'gfedcba' — развёрнутая строка {% endtable %}

Опущенный параметр означает «с начала» или «до конца», но двоеточие при этом обязательно. Третий параметр среза задаёт шаг — так же, как третий параметр range: S[a:b:d] берёт символы с индексами a, a + d, a + 2d и так далее. Отрицательный шаг идёт по строке с конца.

{% program %} s = 'abcdefg' print(s[1]) print(s[-1]) print(s[1:3]) print(s[1:-1]) print(s[:3]) print(s[2:]) print(s[:-1]) print(s[::2]) print(s[1::2]) print(s[::-1]) {% endprogram %} {% program %} s = 'abcdefghijklm' print(s[0:10:2]) for i in range(0, 10, 2): print(i, s[i]) {% endprogram %} {% warning %} Развёртывание строки через s[::-1] работает и со списками, и со строками — это самый короткий способ развернуть последовательность. Обратный срез создаёт новый объект. {% endwarning %} {% tip %} Срез с двумя параметрами никогда не вызывает IndexError: если границы вышли за длину строки, просто обрезаются. s[1:5] и s[1:100] для короткой строки дадут одно и то же значение. Ошибка возможна только при обращении к одному символу. {% endtip %} {% note %} Строки в Питоне неизменяемы: любая операция создаёт новую строку и никогда не меняет исходную. Строго говоря, в Питоне нет и переменных — есть имена, связанные с объектами. Можно связать одно имя с одним объектом, потом переприсвоить его другому, а несколько имён связать с одним объектом. {% endnote %} {% endsection %} {% section "Методы строк" %}

Метод — функция, применяемая к объекту. Вызывается как объект.метод(аргументы). У строк их много, но в задачах чаще всего нужны пять.

{% table 'Самые нужные методы' %} МетодЧто делаетПример для 'Hello' find(t)индекс первого вхождения или -1find('e') → 1 rfind(t)индекс последнего вхождения или -1rfind('l') → 3 count(t)число непересекающихся вхожденийcount('l') → 2 replace(old, new)заменяет все вхожденияreplace('l','L') → 'HeLLo' s[t] + s = s[:-1]удаление символа — только через новую строкуs[:-1] → 'Hell' {% endtable %} {% endsection %} {% section "Поиск подстроки" %}

Метод find возвращает индекс первого вхождения подстроки, а -1, если подстрока не найдена:

{% program %} S = 'Hello' print(S.find('e')) # 1 print(S.find('ll')) # 2 print(S.find('L')) # -1 {% endprogram %}

Метод rfind ищет с конца и даёт индекс последнего вхождения:

{% program %} S = 'Hello' print(S.find('l')) # 2 print(S.rfind('l')) # 3 {% endprogram %} {% warning %} Значение -1 — не ошибка, а обычный результат. Проверяйте найденное так: if S.find('x') >= 0: или if 'x' in S:. Проверка вида if S.find('x'): неверна — ненулевой индекс 1 будет воспринят как ложь, а вот -1 окажется истиной. {% endwarning %}

Методы принимают границы поиска: S.find(T, a) ищет начиная с индекса a, а S.find(T, a, b) — в срезе S[a:b]. Возвращаемый индекс при этом считается от начала всей строки, а не от начала среза.

{% tip %} Когда find используется только для проверки «есть ли», быстрее и понятнее написать if 'x' in S: — так читается намерение, а не способ проверки. {% endtip %} {% endsection %} {% section "Замена и подсчёт" %}

Метод replace заменяет все вхождения одной подстроки на другую и возвращает новую строку:

{% program %} print('Hello'.replace('l', 'L')) print('a, b, c'.replace(', ', ', ')) {% endprogram %}

Третий параметр ограничивает количество замен — будут заменены только первые count вхождений:

{% program %} print('Abrakadabra'.replace('a', 'A', 2)) {% endprogram %}

Метод count считает непересекающиеся вхождения:

{% program %} print('Abracadabra'.count('a')) # 4 print(('a' * 10).count('aa')) # 5, а не 9 {% endprogram %} {% note %} Про ('a' * 10).count('aa'): десять a дают пять непересекающихся пар. Пересекающиеся вхождения — aba внутри aaaa — не считаются. {% endnote %}

Как и find, методы replace и count можно ограничить срезом: s.count(t, a, b) и s.replace(old, new, count).
