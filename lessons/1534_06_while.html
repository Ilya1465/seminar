{% section "Цикл while" %}

Цикл while («пока») повторяет блок кода, пока условие истинно. В отличие от for, он не знает заранее, сколько будет повторов, — условие проверяется заново перед каждой итерацией.

{% snippet 'Синтаксис' %} while условие: блок инструкций {% endsnippet %}

Порядок работы простой: проверили условие — ложно, значит выходим из цикла; иначе выполнили блок и проверили условие снова. Так продолжается, пока условие истинно.

Самый простой цикл while умеет заменять цикл for ... in range(...):

{% program %} i = 1 while i <= 10: print(i ** 2) i += 1 {% endprogram %}

Переменная, значение которой меняется на каждом проходе, называется счётчиком. После цикла i будет равно 11 — это первое значение, при котором условие i <= 10 стало ложным.

{% keyline %} Условие цикла while должно когда-нибудь стать ложным. Если оно всегда истинно, программа зациклится и её придётся прерывать вручную. {% endkeyline %}

Второй пример — считаем количество цифр в числе, отбрасывая по одной цифре с конца:

{% program %} n = int(input()) length = 0 while n > 0: n //= 10 # это эквивалентно n = n // 10 length += 1 print(length) {% inputdata %} 5678 {% endinputdata %} {% endprogram %}

Целочисленное деление на 10 убирает последнюю цифру числа, поэтому количество повторов цикла равно количеству цифр.

{% tip %} Обычно ту же задачу решают короче: len(str(n)) — длина строкового представления числа. Это работает и для отрицательных чисел, у которых минус тоже считается символом, так что len(str(abs(n))) надёжнее. {% endtip %} {% warning %} Забытая строка i += 1 — самая частая ошибка в цикле while. Условие не меняется, цикл крутится вечно и подвешивает вкладку. Если программа «зависла», ищите счётчик, который нигде не увеличивается. {% endwarning %} {% endsection %} {% section "Прерывание цикла" %}

Инструкция break немедленно останавливает ближайший цикл и передаёт управление следующей за ним строке. Условие после прерывания не проверяется.

{% program %} n = int(input()) for i in range(n): a = int(input()) if a < 0: print('Встретилось отрицательное число', a) break print('Обработано число', a) print('Программа продолжает работу') {% inputdata %} 3 6 2 -5 7 {% endinputdata %} {% endprogram %}

Обратите внимание на строку после цикла: она выполнится в любом случае, независимо от того, был ли break. Так удобно выводить итог, который не зависит от причины остановки.

{% tip %} Смысл у break появляется в связке с веткой else у цикла. Блок else выполняется один раз после нормального завершения цикла, а break его отменяет. Получается короткая запись «если цикл дошёл до конца без остановки, сделай то-то»: {% endtip %} {% program %} a = int(input()) while a != 0: if a < 0: print('Встретилось отрицательное число', a) break a = int(input()) else: print('Ни одного отрицательного числа не встретилось') {% inputdata %} 3 6 -1 4 0 {% endinputdata %} {% endprogram %}

Ветку else поддерживает и цикл for:

{% program %} n = int(input()) for i in range(n): a = int(input()) if a < 0: print('Встретилось отрицательное число', a) break else: print('Ни одного отрицательного числа не встретилось') {% inputdata %} 3 6 2 4 {% endinputdata %} {% endprogram %}

В первом варианте последовательность чисел заканчивается нулём — это удобно, когда количество элементов неизвестно. Во втором на вход подаётся сначала длина, и цикл for подходит лучше.

{% warning %} break и continue влияют только на ближайший цикл. Во вложенных циклах внешний продолжит работу. Если нужно выйти сразу из двух уровней, придётся выносить условие в отдельную функцию и возвращаться из неё. {% endwarning %} {% endsection %} {% section "Продолжение цикла" %}

Инструкция continue пропускает остаток тела цикла и сразу переходит к следующей итерации. Полезна, когда часть действий нужно выполнить не всегда:

{% program %} n = int(input()) squares = 0 i = 1 while i <= n: if i % 2 == 1: i += 1 continue # нечётные пропускаем squares += i * i # считаем только чётные i += 1 print(squares) {% inputdata %} 7 {% endinputdata %} {% endprogram %} {% note %} В этом примере i += 1 пришлось написать дважды. Обиднее, чем кажется: забутить increment в одном из путей — классический источник бесконечного цикла. Если условие пропускает шаг, надёжнее двигать счётчик в конце тела, а проверку вынести в условие цикла. {% endnote %} {% warning %} Увлекаться break и continue не стоит, если можно обойтись без них. Вот как выглядит типичное плохое решение — подсчёт цифр через while True и break: {% endwarning %} {% program %} n = int(input()) length = 0 while True: length += 1 n //= 10 if n == 0: break print('Длина числа равна', length) {% inputdata %} 567 {% endinputdata %} {% endprogram %}

Здесь условие цикла спрятано внутри тела, и читателю приходится искать, где же цикл заканчивается. Условие можно вынести наружу и обойтись без break:

{% program %} n = int(input()) length = 0 while n != 0: length += 1 n //= 10 print('Длина числа равна', length) {% inputdata %} 567 {% endinputdata %} {% endprogram %}

И совсем изящное решение:

{% program %} n = int(input()) print('Длина числа равна', len(str(abs(n)))) {% inputdata %} 567 {% endinputdata %} {% endprogram %} {% note %} Отладьте цикл, убрав из него break, и посмотрите, что будет выполняться дальше. Если программа продолжает делать осмысленные действия, значит, ранний выход ей не нужен и цикл можно упростить. {% endnote %} {% endsection %} {% section "Множественное присваивание" %}

За одну инструкцию можно изменить сразу несколько переменных — значения перечисляются через запятую по обе стороны от знака равенства:

{% snippet 'Две записи одного и того же' %} a, b = 0, 1 a = 0 b = 1 {% endsnippet %}

Главное условие — количество элементов слева и справа должно совпадать. Слева стоят имена переменных, справа — произвольные выражения.

Самый известный случай — обмен значений двух переменных. В обычных языках для этого нужна временная переменная:

{% program %} a = 1 b = 2 tmp = a a = b b = tmp print(a, b) {% endprogram %}

В Питоне то же действие занимает одну строку:

{% program %} a = 1 b = 2 a, b = b, a print(a, b) {% endprogram %} {% keyline %} Правая часть вычисляется целиком до присваивания, поэтому a, b = b, a работает, хотя выражения ссылаются на старые значения. {% endkeyline %} {% checklist 'Что мы теперь умеем' %}

  • Останавливать цикл через break
  • Пропускать часть тела через continue
  • Использовать ветку else у цикла
  • Менять несколько переменных одной инструкцией
