{% section "Что такое множество" %}

Множество — структура данных, знакомая ещё со школы: набор различных элементов, где порядок не имеет значения. В Питоне множество умеет отвечать на вопрос «есть ли такой элемент?» намного быстрее, чем список, — и именно ради этого обычно и переходят на set.

Ключевое отличие от списка: элементы хранятся не подряд, а при помощи хеш-таблицы. Проверка принадлежности поэтому занимает постоянное время и не зависит от размера множества. Перебор всех элементов списка занимает время, пропорциональное длине списка.

{% keyline %} Множество отвечает на вопрос «есть ли элемент?» за постоянное время. Список — за линейное. {% endkeyline %}

Элементом множества может быть любой неизменяемый тип: числа, строки, кортежи. Изменяемые типы быть элементами не могут — нельзя добавить в множество список или другое множество, но можно кортеж. Требование неизменяемости вытекает из способа хранения: Питон вычисляет хеш элемента один раз и больше не пересчитывает.

{% warning %} Попытка добавить список во множество даёт TypeError: unhashable type. Если такое произошло, замените список на кортеж: set([1, 2, 3]) → set((1, 2, 3)) или {(1, 2, 3)}. {% endwarning %} {% endsection %} {% section "Создание множеств" %}

Множество задаётся перечислением элементов в фигурных скобках. Пустое множество — исключение: {} в Питоне означает пустой словарь, поэтому для пустого множества используют функцию set().

{% program %} A = {1, 2, 3} A = set('qwerty') print(A) {% endprogram %}

Функция set() принимает список, строку или кортеж и возвращает множество из их элементов. Вывод программы выше — {'e', 'q', 'r', 't', 'w', 'y'}.

Каждый элемент входит в множество только один раз, порядок задания не важен:

{% program %} A = {1, 2, 3} B = {3, 2, 3, 1} print(A == B) {% endprogram %}

Программа выведет True: повторная тройка во множестве B не создала нового элемента. По той же причине set('Hello') даст всего четыре элемента — {'H', 'e', 'l', 'o'}, буквы l в слове дважды.

{% note %} Два множества считаются равными, если содержат одни и те же элементы, независимо от порядка. Списки так не работают: [1, 2, 3] == [3, 2, 1] даёт False. {% endnote %} {% endsection %} {% section "Работа с элементами" %}

Число элементов даёт функция len, перебрать элементы можно циклом for — но помните, что порядок обхода неопределён:

{% program %} primes = {2, 3, 5, 7, 11} for num in primes: print(num) {% endprogram %}

Принадлежность проверяется операцией in, которая возвращает bool. Обратная операция — not in. Добавление элемента — метод add:

{% program %} A = {1, 2, 3} print(1 in A, 4 not in A) A.add(4) print(A) {% endprogram %} {% table 'Способы удаления элемента' %} МетодЭлемент естьЭлемента нет discard(x)удаляетничего не делает remove(x)удаляетKeyError pop()удаляет случайный и возвращает егоKeyError, если множество пусто {% endtable %} {% tip %} Если неизвестно, есть ли элемент, используйте discard: он никогда не прервёт программу. remove удобен там, где отсутствие элемента — это ошибка в логике и её стоит поймать. {% endtip %}

Обратное преобразование — list(A) — возвращает список. Порядок элементов при этом определяется внутренним устройством множества и не гарантируется.

{% endsection %} {% section "Операции над множествами" %}

Над множествами выполняются те же операции, что и в математике. У каждой есть короткая запись через оператор и полная через метод; короткая запись создаёт новое множество, а |= и подобные изменяют исходное на месте.
