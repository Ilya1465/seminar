{% section "Цикл for" %}

Цикл for повторяет блок кода для каждого элемента последовательности. В отличие от большинства языков, здесь не нужно ни объявлять тип счётчика, ни указывать, где остановиться: цикл работает с тем набором значений, который вы перечислили.

В цикле указывается переменная и набор значений, по которому она будет пробегать. Набором может быть список, кортеж, строка или диапазон:

{% program %} i = 1 for color in 'red', 'orange', 'yellow', 'green', 'cyan', 'blue', 'violet': print('#', i, ' color of rainbow is ', color, sep = '') i += 1 {% endprogram %}

Переменная color последовательно принимает значения 'red', 'orange' и так далее. В теле цикла выводится сообщение с названием цвета — то есть со значением color — и номером итерации, который считает переменная i.

{% note %} Инструкция i += 1 — это сокращение для i = i + 1. Такая короткая запись есть у всех арифметических операций: x -= 5, x *= 2, x //= 3. {% endnote %}

Элементы набора могут быть разных типов — цикл это допускает:

{% program %} for i in 1, 2, 3, 'one', 'two', 'three': print(i) {% endprogram %}

В первых трёх итерациях i — число типа int, в следующих трёх — строка типа str. Питон не проверяет однородность набора, поэтому в цикле по разнородным данным придётся проверять тип самостоятельно.

{% endsection %} {% section "Функция range" %}

Чаще всего цикл нужен, чтобы повторить действие заданное число раз или пройти по числам от одного значения до другого. Для этого используют функцию range:

{% program %} for i in range(4): # равносильно for i in 0, 1, 2, 3: print(i) print(i ** 2) print('Конец цикла') {% endprogram %}

Аргументом range может быть константа, переменная или произвольное выражение — например, 2 ** 10. Если значение равно нулю или отрицательно, тело цикла не выполнится ни разу.

{% warning %} range не включает правую границу. range(4) даёт 0, 1, 2, 3 — всего четыре значения, а не пять. Это одинаково для всех форм: range(1, n + 1) — обычный способ получить числа от 1 до n включительно. {% endwarning %} {% program %} sum = 0 n = 5 for i in range(1, n + 1): sum += i print(sum) {% endprogram %}

Третий параметр задаёт шаг. Он может быть отрицательным — тогда цикл идёт в обратную сторону:

{% table 'Три формы range' %} ВызовЗначенияКогда нужен range(n)0, 1, ... n-1повторить действие n раз range(a, b)a, a+1, ... b-1пройти от a до b без b range(a, b, d)a, a+d, ... < bшаг отличный от 1 range(1, 100, 2)1, 3, 5, ... 99только нечётные числа range(100, 0, -1)100, 99, ... 1обратный порядок {% endtable %} {% tip %} Если a ≥ b, цикл не выполнится ни разу. Это удобно, но легко пропустить: опечатка в границах даёт пустой результат без всякой ошибки. Если программа «ничего не делает», в первую очередь проверьте range. {% endtip %} {% keyline %} Формально for i in range(a, b, d) при d > 0 перебирает все значения i = a, a + d, a + 2d, ..., для которых i < b. При d < 0 — все значения i > b. {% endkeyline %} {% endsection %} {% section "Настройка функции print()" %}

По умолчанию print() печатает аргументы через пробел и ставит перевод строки. Именованные параметры sep (разделитель) и end (окончание строки) это поведение меняют. Полезнее, чем кажется: без end нельзя напечатать несколько чисел в одну строку, а это нужно почти в каждой задаче на вывод.

{% program %} print(1, 2, 3) print(4, 5, 6) print(1, 2, 3, sep=', ', end='. ') print(4, 5, 6, sep=', ', end='. ') print() print(1, 2, 3, sep='', end=' -- ') print(4, 5, 6, sep=' * ', end='.') {% endprogram %} {% note %} Пустой вызов print() печатает пустую строку — это самый простой способ отделить один блок вывода от другого. Иногда удобнее передавать sep='' и склеивать всё в одну строку, чтобы потом разобрать её с помощью split() — об этом пойдёт речь в уроке про строки. {% endnote %} {% checklist 'Что мы теперь умеем' %}
