# Модернизация публичного архива PythonTutor

Пользователь выбрал модернизацию публичного архива 2017 года (Behnisch/pythontutor-ru, 1a9193f) вместо заявления о побайтовой копии рабочего сервера. Сохраняем материалы, тесты, визуализатор, регистрацию, профили, прогресс и учительские функции архива. Текущий сайт содержит 11 разделов и 128 задач; совпадение количества с архивом не доказывает совпадение содержания.

## Архитектура

Актуальный Django LTS, Python 3.14.7, SQLite в постоянном томе для автономной небольшой установки. Исходные HTML-шаблоны и материалы сохраняются; несовместимые API заменяются. CSRF, валидация ввода и проверка прав обязательны. База создаётся миграциями и идемпотентным импортом учебного курса; демонстрационные пользователи из example.db не переносятся.

Выполнение ученического Python отделено от веб-приложения: одноразовые контейнеры без сети, с ограничениями времени, памяти, процессов и вывода. Нет автоматического перехода к незащищённому exec при недоступном Docker. Отладочная трасса совместима с визуализатором архива. Веб-приложение обращается к внутреннему сервису запуска; Docker socket не доступен ученикам.

Статика поставляется локально; реклама, аналитика и социальные виджеты не требуются для самостоятельного размещения. Авторство и лицензии MIT / CC BY-NC-SA сохраняются. OAuth требует собственных настроек провайдера и не является условием локального входа.

## Приёмка

Чистая установка, миграции, импорт всех валидных задач с равным количеством входов и ответов; повторный импорт не теряет прогресс. Регистрация, вход, выход, корректное/ошибочное решение, сохранение результата, пошаговая трассировка, доступ учителя. Исполнение бесконечного цикла завершается по лимиту; сетевой доступ и запись на хост не предоставляются. Проверка приложения через браузер. Docker Compose, инструкции запуска/переноса/резервного копирования и отчёт о проверках.

## Уточнение пользователя: OpenCV и изображения

Все рабочие Docker-образы используют последнюю стабильную Python 3.14.7 (проверено на python.org 2026-09-27). В контейнере выполнения установлены OpenCV headless 5.0.0.93, NumPy 2.5.3 и Pillow 12.3.0. Восемь новых задач имеют 24 фиксированных теста изображений. Загрузка ограничена PNG/JPEG, 2 МиБ и 4 миллионами пикселей. Временные input.png/output.png живут только в отдельном контейнере. Сохраняются код и прогресс; преподаватель выдаёт задания конкретному ученику либо всей группе и видит результаты.
