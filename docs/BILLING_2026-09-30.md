# Тарифы, промокоды и админ-функции — 30.09.2026

## Что добавлено

### Тарифы (Free / Premium)
- `UserProfile.plan` (`free`/`premium`) и `UserProfile.premium_until` (дата окончания). Если `premium_until` прошла, тариф автоматически возвращается к `free` (`UserProfile.effective_plan`).
- Миграция `0009_userprofile_plan_userprofile_premium_until_promocode`.
- `tutorial/billing.py`:
  - `PLANS` — справочник тарифов (название, цена).
  - `ai_daily_limits()` / `ai_daily_limit(user)` — дневной лимит ИИ-помощника (Free = `TUTOR_AI_DAILY_LIMIT` = 60, Premium = `PREMIUM_AI_DAILY_LIMIT` = 180). Читаются в момент вызова, поэтому `override_settings` в тестах работает.
  - `api_multiplier(user)` — множитель rate-limit (Free = 1, Premium = `PREMIUM_API_MULTIPLIER` = 3).
  - `activate_premium(profile, days)`, `revoke_premium(profile)`, `redeem_code(code, user)`.
  - `PaymentProvider` / `TestPaymentProvider` / `get_payment_provider()` — абстрактный платёжный слой. Сейчас `test`: реальный шлюз (ЮKassa/Robokassa) подключается подменой `PAYMENT_PROVIDER` без изменения остального кода.

### Промокоды
- Модель `PromoCode` (код, дней премиума, заметка, кем/когда использован). Одноразовые, активация продлевает текущий срок.
- Страница `/tariff/`: карточки тарифов, ввод промокода, пояснение «оплата ещё не подключена — обратитесь к администратору за промокодом».

### Применение лимитов
- `views/assistant.py` — лимит ИИ по тарифу, в тексте 429 упоминается «Премиум».
- `middleware.py RequestQuotaMiddleware` — лимиты `execute`/`tester`/`images`/`browser submit`/`assistant` умножаются на `api_multiplier(user)` для авторизованных.

### Админ-функции
- `UserProfileAdmin`: поля «Тариф»/«Премиум до», фильтр по тарифу, колонка «Тариф» (зелёным — активный Premium со сроком), действия **«Выдать Премиум на 30 дней»**, **«Выдать Премиум на 180 дней»**, **«Отозвать Премиум»**.
- `PromoCodeAdmin` (только суперпользователь): список, поиск, действие «Пометить использованными».
- `/statistics/`: блок «Тарифы и подписки» (активные Premium, истекают за 7 дней, свободные, промокоды) + ссылки на админку. Виден только суперпользователю.

### Удобство для обычного пользователя
- Главная: раздел **«С чего начать»** (4 шага) + блок про тарифы/регистрацию.
- Навбар и футер: ссылка «Тарифы» для авторизованных.
- Профиль: блок «Ваш тариф: … (до …) · Подробнее о тарифах».

### Настройки (.env)
- `PREMIUM_AI_DAILY_LIMIT=180`, `PREMIUM_API_MULTIPLIER=3`, `PREMIUM_PRICE=299`, `PAYMENT_PROVIDER=test`.
